# Personal Finance Application

Aplicação web desenvolvida em **Java** com **Spring Boot**, voltada para o gerenciamento de finanças pessoais. O objetivo do projeto é permitir o controle de receitas, despesas e informações financeiras de forma simples e organizada. Além disso, o desenvolvimento foi estruturado em commits incrementais, demonstrando a evolução da atividade passo a passo.

## Tecnologias

- Java
- Spring Boot
- Maven
- Banco de dados relacional
- JPA / Hibernate
- Git e GitHub

## Commits

Os commits do projeto foram separados por etapas, seguindo uma padronização para facilitar o entendimento da evolução da aplicação:

- `init`: preparação inicial do projeto;
- `feat`: adição de novas funcionalidades;
- `fix`: correção de problemas encontrados durante o desenvolvimento;
- `refactor`: reorganização e melhoria do código sem alterar o comportamento da aplicação;
- `chore`: tarefas auxiliares, configurações e ajustes gerais;
- `test`: configuração e implementação de testes.

## Status

Projeto desenvolvido para fins acadêmicos, com foco na prática de desenvolvimento web utilizando Java, Spring Boot e versionamento com Git.
